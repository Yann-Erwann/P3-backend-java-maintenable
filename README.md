# ChaTop

Application de location immobilière avec un frontend Angular, un backend
Spring Boot et une base de données MySQL.

Les instructions d’installation, de configuration et de lancement se trouvent
dans le [README du backend](backend/README.md).

Les informations du frontend se trouvent dans le [README du frontend](frontend/README.md).

Les conventions de contribution, les commandes de vérification et les contrôles
avant commit sont décrits dans [CONTRIBUTING.md](CONTRIBUTING.md).

La documentation de l’API est accessible via [Swagger UI](http://localhost:8081)
après le démarrage du projet.
